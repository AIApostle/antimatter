# Always Commit Rule

Whenever changes are made to the codebase (source code, tests, documentation, or configurations):
1. **Always verify** the changes with tests (`uv run pytest`, `npm run build`).
2. **Always commit** the changes to git immediately using conventional commits (e.g. `feat:`, `fix:`, `refactor:`, `chore:`).
3. Do not leave uncommitted modifications in the working tree.
